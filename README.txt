Q.T.S Scheduler Ver.6.2

主な追加機能
- 案件詳細に「お客様」「工場」「搬入業者」「大工」を追加
- 各項目に会社名/名称、担当者、電話番号、メモを登録可能
- 案件詳細画面の「編集」から直接入力・更新
- 保存後は見やすいカード表示
- スマホでは電話番号をタップして発信可能
- 関係者情報は年間予定表Excelとは別にFirestoreへ保存
  → 将来Excelを更新しても入力済み情報は保持されます
- Ver.6.1.1までの年間案件票、関連予定、アイコン等は維持

保存先
Firestore collection: projectContacts
案件番号ごとのdocumentとして保存します。

更新方法
このZIPを展開し、中のファイルをGitHubの schedule-Desk にアップロードしてください。
同名ファイルは置き換えてください。

注意
関係者情報の保存時に権限エラーが出る場合は、
Firestoreのセキュリティルールで projectContacts collection の読み書き許可が必要です。
