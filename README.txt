Q.T.S Scheduler Ver.6.3 試作版

目的
複数人利用を始める前に「自分専用ページ」と「全員共有」の使い勝手を確認する試作です。

追加内容
- 起動時に 村口 / 金子 / 寺門 を選択
- 選んだ利用者ごとの「自分のホーム」
- 自分専用 / 全員共有 の表示切替
- 今日の自分の予定、今週の自分の予定、担当案件の件数表示
- 年間案件一覧も自分担当だけに絞り込み可能
- 端末ごとに選択した利用者を記憶
- Ver.6.2までの案件詳細・関係者情報・年間予定表・アイコンを維持

重要
このVer.6.3は試作版です。
表示上の利用者切替であり、パスワード認証ではありません。
URLを知っている人のアクセスを防ぐセキュリティ機能はまだありません。

本格導入時
Firebase Authenticationを利用し、各ユーザー専用アカウント・ログイン・アクセス制御へ移行する予定です。

更新方法
ZIPを展開し、中のファイルをGitHubの schedule-Desk にアップロードしてください。
同名ファイルは置き換えてください。
