Q.T.S Scheduler Ver.6.3

主な変更
- Firebase Authenticationによるメール/パスワードログイン
- 村口 / 金子 / 寺門 の利用者プロフィール
- 共有予定は従来の schedules をそのまま使用
- 「🔒 プライベート予定」を追加
- プライベート予定は本人専用Firestore領域へ保存
- 他ユーザーはプライベート予定の存在自体を取得できない設計
- プライベート予定には本人の画面だけ🔒マークを表示
- 共有⇔プライベートの変更に対応
- 完了、削除、ドラッグ移動・コピーもプライベート予定に対応
- Ver.6.2までの案件詳細・年間予定表・関係者情報・アイコンを維持

重要:
初回だけFirebase AuthenticationとFirestore Rulesの設定が必要です。
必ず SETUP_Ver6_3.txt を読んでから運用してください。
