Q.T.S Scheduler Ver.6.8.11

【今回の修正：⑦ デスクトップアイコン】
1. ZIPに不足していた favicon.ico を追加
2. ZIPに不足していた manifest.webmanifest を追加
3. Windowsデスクトップ用の専用アイコン qts-scheduler.ico を追加
4. Create_QTS_Desktop_Shortcut.bat を追加
   - ダブルクリックすると、デスクトップの「Q.T.S Scheduler」ショートカットを作り直します
   - 既存の同名ショートカットがある場合は置き換えます
   - ショートカットはQ.T.S専用アイコンを直接使用します

【使い方】
1. ZIPを必ずフォルダごと展開してください
2. index.htmlだけを単独で移動しないでください
3. 展開したフォルダ内の Create_QTS_Desktop_Shortcut.bat を1回ダブルクリックしてください
4. デスクトップに「Q.T.S Scheduler」が作成されます

※ Ver.6.8.10 の①③④⑤⑥の修正内容はそのまま維持しています。
