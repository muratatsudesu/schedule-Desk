Q.T.S Scheduler Ver.6.6

経費メモ基本版

追加機能
- 予定カードの「コピー」と「編集」の間に「💰経費」ボタンを追加
- 経費区分：通常交通費 / 出張
- 移動明細：電車 / 車・高速 / タクシー / バス / その他
- 乗車駅・乗IC、降車駅・降IC、路線・高速区間、金額
- 1予定に複数区間を登録可能
- 領収書あり / 精算済み / メモ
- 登録済みの予定カードに合計金額と精算状態を表示

安全・無料を優先し、Ver.6.6では経費メモを外部APIや新しいFirebase設定を使わず、
ログイン利用者ごとのブラウザ localStorage に保存します。
そのため、別PC・別ブラウザには同期されません。ブラウザデータ削除時には経費メモも消えます。
まず操作性を確認するための基本版です。

既存のスケジュール / 年間予定表 / Firebase予定データには構造変更を加えていません。
