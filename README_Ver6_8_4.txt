Q.T.S Scheduler Ver.6.8.4
出張交通費複数区間安定化＋未保存警告版

変更点
- 同じ出張経費メモ内の複数移動区間を、1区間ずつ漏れなく旅費精算Excelへ出力
- 複数区間の重複排除ロジックを廃止（同経路を実際に複数回使うケースも保持）
- 保存直後にlocalStorageの保存区間数を照合
- Excel出力前に保存済み区間数と出力区間数をチェック
- 経費メモを編集後、× / キャンセル / 背景クリック / Escで閉じる際に未保存警告
- 未保存状態でExcel出力しようとした場合に警告
- ブラウザ更新・タブ終了時も未保存ならブラウザ標準警告

維持
- 日当 1日2,000円（移動日含む）
- 宿泊費 1泊単価×泊数、日別表示
- 業務費は出張単位で1回計上
- 外部APIなし・端末内保存
